# Counter component

## Requirements

Create a react component that should allow the user to increment/decrement
a count.

- A `(-)` button on the left to decrement
- A count value that starting with zero and should be reactive as per buttons interactions
- A `(+)` button ton the right to increment

## Constraints

- Count value can be exposed letter but optional
- Component should be uncontrolled/functional and it should manage its state itself.
-

## API design

- No inputs
- Count `optional` output

## Accessibility

- Nice, to have.

## Minimal style

- Not necessary since it's a demo component.
